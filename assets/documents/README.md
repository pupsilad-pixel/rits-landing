# Юридические документы

Перед публикацией положите в эту папку два файла без изменения имён:

- `user-agreement.pdf` — пользовательское соглашение;
- `privacy-policy.pdf` — политика обработки персональных данных, Cookie и аналитика.

Ссылки на эти документы уже подключены в подвале и в форме заявки.
