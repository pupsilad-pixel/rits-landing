# RITS — лендинг

Одностраничный сайт IT-аутсорсинговой компании RITS, свёрстанный по макету.
Чистая статика: HTML + CSS + vanilla JS, без сборки и зависимостей.

## Запуск

```bash
python -m http.server 5173
```

Затем открыть http://localhost:5173

Открытие `index.html` напрямую через `file://` тоже работает, но локальный сервер
надёжнее (некоторые браузеры ограничивают загрузку соседних файлов по `file://`).

## Структура

```
index.html        разметка всех секций + SVG-спрайт иконок
css/styles.css    токены дизайна, компоненты, адаптив
js/main.js        меню, reveal-анимации, счётчики, схема экосистемы, модалка
.claude/launch.json  конфиг локального dev-сервера
```

## Добавление новости

1. Скопируйте `news/ARTICLE-TEMPLATE.html` и переименуйте файл латиницей.
2. Замените поля с пометкой `НОВАЯ НОВОСТЬ`.
3. Добавьте изображение в `assets/news/`; размер подгоняется автоматически.
4. В `news/index.html` скопируйте первый блок между комментариями
   `НОВУЮ КАРТОЧКУ КОПИРОВАТЬ ОТСЮДА` и `КОНЕЦ КАРТОЧКИ`.
5. Поменяйте ссылку, дату, изображение, название и краткое описание.

## Схема «Всё IT — в одной системе»

Соединительные линии между карточками и ядром рисует `drawLinks()` в
`js/main.js`: он берёт фактические координаты карточек и строит кубические
кривые к окружности ядра. Пересчёт идёт на `resize`, через `ResizeObserver` и
после загрузки шрифтов, поэтому линии остаются на месте при любой ширине и
длине текста. На экранах уже 900px колонки складываются в столбик и линии
скрываются (`.orbit__links{display:none}` — скрипт это учитывает и не рисует их).

Координаты считаются относительно самого блока `.orbit`, поэтому reveal-анимация
(`transform` на родителе) на расчёт не влияет — по этой же причине карточки
внутри проявляются только через `opacity`, без сдвига.

## Дизайн-токены

Заданы CSS-переменными в `:root` (`css/styles.css`). Основа — четыре
фирменных цвета, всё остальное получено из них осветлением/затемнением.

| Переменная | Значение | Из брендбука | Назначение |
|---|---|---|---|
| `--blue` | `#5DB4EE` | **WIN OS** | акцент: заливки, иконки, индикаторы |
| `--blue-ink` | `#1F7FC0` | затемнённый WIN OS | текстовые акценты и ссылки |
| `--blue-dark` | `#2A82BE` | затемнённый WIN OS | градиенты, hover |
| `--blue-soft` | `#A6D7F4` | осветлённый WIN OS | подсветка, стрелки |
| `--gray` | `#D0D2DF` | **SERVER GRAY** | фоны, разделители |
| `--lav` | `#E3EDF6` | производная | подложка иконок |
| `--surface` | `#F2F4F8` | производная | поля ввода, светлые плашки |
| `--bg` | `#ECEEF4` | производная SERVER GRAY | фон страницы |
| `--white` | `#FFFFFF` | **NEW TAB** | карточки, поверхности |
| `--ink` | `#2D3036` | **CLI WINDOW** | заголовки, подвал, тёмные блоки |
| `--ink-2` / `--muted` / `--muted-2` | `#3D424B` / `#666C77` / `#8A909C` | производные CLI WINDOW | текст по убыванию контраста |

Почему два синих для одного цвета: чистый `#5DB4EE` на белом даёт контраст
~2:1 — этого хватает для заливок и иконок, но не для текста. Поэтому ссылки,
цифры в кейсах и подписи-чипы используют `--blue-ink` (~4,7:1, проходит WCAG AA),
визуально оставаясь тем же тоном.

Единственный цвет вне брендбука — красный `#D93A45` для ошибок валидации формы.
Функциональный сигнал ошибки нечем заменить внутри четырёх основных цветов;
если в брендбуке есть дополнительная палитра со статусными цветами — пришлите,
поправлю.

Шрифты: **Manrope** (заголовки и UI) + **Inter** (текст), подключены с Google Fonts.

## Что нужно доделать перед продакшеном

- **Юридические документы.** Положить предоставленные PDF в `assets/documents/`
  под именами, указанными в `assets/documents/README.md`.
- **Изображения кейсов** сейчас нарисованы CSS-градиентами и SVG-паттернами —
  заменить на реальные фотографии объектов.
- **Аналитика** (Метрика/GA) не подключена.

## Поддержка браузеров

Современные версии Chrome, Firefox, Safari, Edge. Есть фолбэки: без
`IntersectionObserver` все блоки показываются сразу. Учтён
`prefers-reduced-motion` — анимации отключаются.
